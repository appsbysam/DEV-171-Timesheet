BUG FIXES
---------

COPY PREVIOUS WEEK
------------------
• Fixed Copy Previous Week failing to find some older records.
• The app first searches for the correct Monday-based previous week.
• If no records are found, it also checks the legacy Sunday-based week date used briefly by an older release.
• Legacy records are still copied into the correct currently selected Monday-based week.
