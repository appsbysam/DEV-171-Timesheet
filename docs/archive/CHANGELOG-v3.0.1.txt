AUTOMATIC VERSION CHECKER
-------------------------
• The app checks the deployed version.js whenever the page loads.
• The check bypasses the browser cache.
• If a newer deployed version is detected, a small message appears:
  “A new version is available. Loading now…”
• The app then reloads automatically using a fresh URL.
• No version details or changelog are shown to the user.
• A session safeguard prevents repeated automatic reload loops.
• The checker works in both DEV and production.

DYNAMIC ENVIRONMENT VERSIONING
------------------------------
• Production displays Version 3.0.1.
• DEV displays Version 3.0.1-dev.
• config.js continues to control the environment suffix.
• The same shared files can be deployed to both repositories.
